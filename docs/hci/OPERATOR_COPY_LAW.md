# Operator Copy Law v1

Operator copy must say permission when an authorization exists. It must not imply
task finish, merge state, release state, human ratification, OG-10, M2 enablement,
or class disposition.

Macro PR, CI, tests, and exit code are external evidence only. They become
sovereign state only through MicroTape predicates, approvals, receipts, and
replay-derived heads.

Approval card visible copy must show action, target, risk, source heads, evidence
digest count, approval requirement, expiry or nonce when present, side-effect
class, and exact post-approval state.

copy-law-allow-list: accepted verified passed merged done completed constitutional approved closed
